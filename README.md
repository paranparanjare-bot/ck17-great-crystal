# CK17 Great Crystal — DPC Banyuwangi

Website statis CK17 Great Crystal DPC Banyuwangi (HTML + CSS + vanilla JS,
tanpa backend). Diresmikan 19 November 2026 di Blambangan Ballroom,
Aston Hotel Banyuwangi.

## Halaman

- `index.html` — halaman utama: apa itu CK17, DPC Banyuwangi, 6 sasana, instruktur
- `kegiatan.html` — daftar kegiatan (saat ini: Peresmian DPC Banyuwangi)
- `peresmian.html` — cerita peresmian, 9 babak
- `galeri.html` — album foto (198 momen; foto dipilih Eko setelah website selesai)
- `video.html` — video YouTube @greatcrystal (3 video tersemat)
- `bergabung.html` — cara bergabung (nomor kontak masih dummy)
